The Digital Historian's Toolbox is a curated catalogue of the software tools and public datasets historians have actually used, including newer AI tools. Entries come from vetted public submissions, and a network graph links each study to the tools it used.

It is a collection, not a set of tutorials. Research uses are kept separate from corpus building and from benchmarks, and AI tools carry historian's notes on where sources go, how the tool has been tested, and how it fails on historical material.
