# jacobpolay.ca

The source of Jacob Polay's academic site, https://jacobpolay.ca. It is a static [Astro](https://astro.build) site served by a Cloudflare Worker. Every push to `main` rebuilds and redeploys it.

## Updating the site

Almost everything lives in small text files under `src/content/`. To add something, copy an existing file next to it, rename it, change the fields, then commit and push.

| To change… | Edit |
|---|---|
| A project | `src/content/projects/<name>.md`. The fields at the top (between the `---` lines) set the card and the graph; the text below is the project page. |
| A publication | `src/content/publications/<name>.yaml`. The Cite button's Chicago and BibTeX citations are generated from these fields. Add `doi:` if a piece gets one. |
| A talk | `src/content/talks/<name>.yaml` |
| The Now page | `src/content/now.md`. Update `updated:` too. |
| The CV page | `src/data/cv.ts`, and replace `public/Polay_Jacob_CV.pdf` with the new PDF |
| Email, profiles, land acknowledgement, colophon | `src/site.ts` |
| Headshot | Put `headshot.jpg` in `public/` and set `headshot: '/headshot.jpg'` in `src/site.ts` |

### Connecting things in the projects graph

A project, publication or talk can list others in `related:`, using ids like `talk:fitting-machine-to-page`, `publication:archive-is-not-a-toy` or `project:toolbox`. The id is the kind plus the file name without its extension. People listed in `collaborators:`, `authors:` or `presenters:` become shared nodes, and a method appears once two or more projects list it. If you mistype an id, the build stops and names the bad id.

### Dates

Use `YYYY-MM-DD`, or `YYYY` for a publication with no exact date. Write it in quotes, for example `date: "2026-10-16"`.

## Running it on your computer

You need Node.js 22.12 or later.

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Checks

```bash
npm test
npm run test:e2e
```

`npm test` runs the unit tests (period spelling, citations, the graph). `npm run test:e2e` builds the site and checks every page in a browser: links, accessibility in light and dark, phone widths, JavaScript turned off, and that no third-party requests are made. Run `npx playwright install chromium` once before the first e2e run.

## Share card and favicons

`public/og.png`, `public/favicon.svg`, `public/favicon-32.png` and `public/apple-touch-icon.png` are generated by:

```bash
node scripts/make-images.mjs
```

Re-run it after changing your name, tagline or role, then commit the images. It uses Windows' Segoe UI Symbol for the ❦; on another computer, set `FLEURON_FONT` to a font that has that character.

## Deployment

`wrangler.jsonc` describes the Cloudflare Worker (`jacobpolay-ca`), which serves `dist/` on `jacobpolay.ca` and `www.jacobpolay.ca`. Cloudflare Workers Builds runs `npm run build` and then `npx wrangler deploy` on every push to `main`. A redirect rule in the Cloudflare dashboard sends `www.jacobpolay.ca` to `jacobpolay.ca`.
